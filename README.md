# Signal: Autonomous GTM & ICP Discovery Engine

> Autonomous GTM & Ideal Customer Profile discovery engine for scaling startups. Built with Frevana for the SF Tech Week Frevana Agent App Hackathon.

![Signal Logo](logo.png)

## Overview
Early-stage B2B and developer tool founders waste weeks pitching the wrong buyer persona with cold outreach that goes to spam. **Signal** autonomously deconstructs any startup description, GitHub repository, or URL into its highest-converting Ideal Customer Profile (ICP), active buying trigger signals, multi-touch outbound battlecards, and an interactive financial pipeline velocity model.

## Features
- **Autonomous GTM Intelligence**: Extracts key domain signals and synthesizes tailored buyer personas with verified pain points.
- **Live Market Telemetry**: Real-time queries to Hacker News Algolia and GitHub REST APIs for authentic discussions, stargazers, and ecosystem trends.
- **Multi-Touch Outbound Sequences**: Generates diagnostic hooks, case proof follow-ups, and breakup teardown templates with 1-click clipboard copying.
- **Pipeline Velocity Model**: Dynamic SVG spline wave modeling ARR trajectory, CAC payback periods, and closed pipeline based on ACV and outreach volume.
- **Multi-Format Export**: 1-click export to structured JSON, Apollo/HubSpot CRM-compatible CSV, and full Markdown playbooks.
- **Procedural Web Audio**: Clean micro-acoustic feedback on interactions without external audio dependencies.

## Built With
- **Frevana Agent Engine** (App Directive v1 & Host Bridge)
- **Vanilla JavaScript** (Zero high-frequency state re-renders)
- **Tailwind CSS**
- **Public APIs**: Hacker News Algolia Search API & GitHub REST API
